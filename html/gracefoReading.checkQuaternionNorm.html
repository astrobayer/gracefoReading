gracefoReading.checkQuaternionNorm

Verify unit norm of SCA1B attitude quaternions.

Syntax

[ok, stats] = gracefoReading.checkQuaternionNorm(obs, aux)
[ok, stats] = gracefoReading.checkQuaternionNorm(obs, aux, Name, Value)

Description

Checks, record by record, that the star-camera attitude quaternion read from an SCA1B product has unit norm - a cheap and effective detector of parsing errors, column mix-ups and corrupt records before the attitude data enter any rotation. The four components are located by name (quatangle, quaticoeff, quatjcoeff, quatkcoeff) in aux.obsNames, so obs can be passed exactly as returned by readL1b. Rotation and coordinate transformations are deliberately out of scope for this toolbox; only the norm sanity check is provided.

Input Arguments

NameTypeSizeDescriptionOptionsDefault
obsdouble[N x M]Observation matrix from readL1b or readL1bMulti of an SCA1B product.
auxstruct1x1Matching aux output; aux.obsNames is used to locate the four quaternion columns.
'Tolerance'double1x1Maximum allowed absolute deviation |norm(q) - 1| per record.any positive value; 1e-6 is loose enough for the ASCII rounding of the products and tight enough to expose real problems1e-6

Output Arguments

NameTypeSizeDescriptionOptionsDefault
oklogical[N x 1]True where |norm(q) - 1| <= Tolerance.
statsstruct1x1
  • n – double: records checked
  • numViolations – double: count of ok == false
  • maxDeviation – double: max |norm(q) - 1|
  • rmsDeviation – double: rms of (norm(q) - 1)
  • tolerance – double: tolerance used
  • columns – double [1 x 4]: obs column indices in the order quatangle, i, j, k

Accuracy and Limitations

  • The ASCII products store quaternion components with finite digits, so a small nonzero deviation is normal; real SCA1B files typically show |norm-1| of order 1e-9 to 1e-8.
  • Unit norm is necessary but not sufficient for correctness: a quaternion can be normalised and still describe a wrong attitude, and a sign flip (q and -q describe the same rotation) is invisible to this test.
  • The check requires all four components in obs; if a product stores any of them as an auxiliary column the function raises columnsNotFound rather than guessing.
  • No renormalisation is performed. Correcting attitude data is left to the processing that uses it.

Errors

Error identifierCondition
gracefoReading:checkQuaternionNorm:columnsNotFoundone of the four quaternion columns is absent from aux.obsNames, i.e. obs is not from an SCA1B-like product

Examples

quick verdict for one day

[t, q, aux] = gracefoReading.readL1b('SCA1B_2020-01-01_C_04.txt');
[ok, stats] = gracefoReading.checkQuaternionNorm(q, aux);
fprintf('max |norm-1| = %.3g, violations: %d\n', ...
       stats.maxDeviation, stats.numViolations);

inspect the offending epochs

bad = find(~ok);
disp(t(bad, :));
