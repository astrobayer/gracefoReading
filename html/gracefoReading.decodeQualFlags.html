gracefoReading.decodeQualFlags

Decode a bit-string flag column using the file's own header.

Syntax

[bits, report] = gracefoReading.decodeQualFlags(aux)
[bits, report] = gracefoReading.decodeQualFlags(aux, flagName)

Description

Decodes a bit-string flag column of a previously read Level-1B product into a logical matrix and summarises how often each bit is set. The bit meanings are taken from the flag_meanings attribute in aux.variableAttributes: for GRACE-FO parsed out of the product file's own header, so the decoding always matches the file actually read; for classic GRACE, whose headers carry none, supplied by readL1b from the product's table in the GRACE Level-1B handbook (JPL D-22027 v1.3, chapter 6) since release 1.3.0. Bits without a documented meaning are still reported, marked as not documented.

Input Arguments

NameTypeSizeDescriptionOptionsDefault
auxstruct1x1Third output of gracefoReading.readL1b or readL1bMulti. Must contain the raw flag field as char [N x B] and the variableAttributes struct.
flagNamestring | char1x1Name of the flag variable to decode.'qualflg', 'prod_flag', or any other bit-string column present in aux'qualflg'. Optional, positional

Output Arguments

NameTypeSizeDescriptionOptionsDefault
bitslogical[N x B]Column b corresponds to bit b-1; bit 0 is the rightmost character of the bit string, following the GRACE-FO convention.
reporttable[B x 4]One row per bit, variables:
  • bit – double: bit number (0-based)
  • meaning – string: meaning from the header, or "(not documented)"
  • countSet – double: records with this bit set
  • fracSet – double: fraction of records, range 0 to 1

Accuracy and Limitations

  • Decoding is exact: it is a character comparison, not a numerical conversion.
  • Meanings are only as complete as the header of the file at hand. Different releases document different bits, and some products document none, in which case every meaning reads "(not documented)" - this is a property of the data, not a failure of the function.
  • The order in which flag_meanings entries map to bit numbers follows the file's declaration order, assumed to start at bit 0. Where a header lists fewer meanings than the flag has characters, the surplus bits stay undocumented.
  • Applies to bit-string columns only. Classic GRACE qualflg is a byte in the binary files; readL1b renders it as the same 8-character bit string, so it decodes here unchanged.

Errors

Error identifierCondition
gracefoReading:decodeQualFlags:flagNotFoundthe requested flag column is not present in aux
gracefoReading:decodeQualFlags:notBitStringthe requested column is not a character bit string

Examples

quality flags of an SCA1B day

[t, q, aux] = gracefoReading.readL1b('SCA1B_2020-01-01_C_04.txt');
[bits, report] = gracefoReading.decodeQualFlags(aux);
disp(report)

which MAS1B columns are actually present (prod_flag)

[~, ~, auxM] = gracefoReading.readL1b('MAS1B_2020-01-01_C_04.txt');
[~, rep] = gracefoReading.decodeQualFlags(auxM, 'prod_flag');
disp(rep(rep.fracSet > 0, :))
