gracefoReading.readEventList

Read an official GRACE/GRACE-FO event list (TN-01, TN-01a).

Syntax

events = gracefoReading.readEventList(fileName)
events = gracefoReading.readEventList(fileName, Name, Value)
[events, aux] = gracefoReading.readEventList(___)

Description

Reads the two official event lists the project publishes beside the Level-1 data and returns one table row per event, with the provenance of every row (G-05, issue #20):

TN-01 "sequence of events", machine-readable. Each line is <epoch> <satellite> <key> <count> <count values> <free text>, where epoch is GPS seconds past 2000-01-01 12:00 and a leading "x" disables the line. The manoeuvres are the rows whose key is MANV. TN-01a "spacecraft events", written by the operators. Entries are grouped under a YYYY-MM-DD date; an entry starts at the indentation of the date field and wrapped text is indented deeper.

**This function reads; it does not interpret.** The values of a TN-01 row are returned as the numbers the file gives, under the key the file gives, and a TN-01a entry is returned as its date and its text. Nothing is inferred that the list does not state - turning these rows into mask layers and calibration windows is the business of the preprocessing chain, which knows what it wants them for. That division is why the text and the line number travel with every row.

Output Arguments

NameTypeSizeDescriptionOptionsDefault
eventstable[N x 8]One row per event, in file order; N = rows kept. Variables:
  • time – double [N x 2]: or datetime [N x 1]
  • satellite – string: "" for a TN-01a entry
  • key – string: the TN-01 key, "" for TN-01a
  • values – cell: the TN-01 numeric values as a row vector, {} for TN-01a
  • text – string: the free text of the row
  • disabled – logical: true for a TN-01 line commented out with a leading "x"
  • dayOnly – logical: true when the file gave a DATE and no time of day, which is every TN-01a row. Such a time is the start of that day and must not be read as an instant.
  • line – double: line number in the source file
auxstruct1x1fileName, format ("soe" | "sce"), numRows, numDisabled, numUnparsable, unparsableLines (double [U x 1]), headerComments (string [H x 1], the leading "#" lines) and timeSystem. timeSystem is "GPS" for an SOE, whose epochs are GPS seconds, and "date" for an SCE, whose dates carry no time scale at all.

Accuracy and Limitations

  • **TN-01a is prose.** Its entries are a human log; only the date and the entry text are structured, and this function returns exactly those. Extracting a manoeuvre window from a sentence like "performed a calibration maneuver from 06:19:26 to 06:21:33 (2.0 cm/sec)" is pattern-matching over free text written by different operators over years, and is deliberately NOT done here.
  • Where a TN-01a entry ends and the next begins is decided by indentation: a line indented as far as the date field starts an entry, a deeper one continues it. That is the file's own convention, stated in its header, and it is the only rule available; a misaligned line would be joined to its predecessor. The line number of every row is returned so a caller can check.
  • A TN-01 epoch of 0 is what the file uses for an initial default rather than a real event. It converts to 2000-01-01 12:00 GPS like any other zero and is NOT filtered out, because which defaults matter is the caller's decision.
  • TN-01 epochs are GPS seconds past the same epoch the L1B products use, so they need no leap-second handling. TN-01a dates are calendar dates as the operators wrote them; no time scale is stated in the file and none is assumed here.
  • A TN-01 line whose value count does not match its declared count, or whose values are not numeric, is not guessed at: it is left out and its line number is reported in aux.unparsableLines.

Examples

every manoeuvre of GRACE-C, as datetimes

ev = gracefoReading.readEventList('TN-01_SOE.txt', ...
   'Satellite', "GRACEC", 'TimeFormat', "datetime");
manv = ev(ev.key == "MANV", :);
fprintf('%d manoeuvre(s), first %s\n', height(manv), manv.time(1));

the operators' log for one day

sce = gracefoReading.readEventList('TN-01a_SCE.txt');
onDay = sce(sce.time(:,1) == 58849, :);
disp(onDay.text);

what the reader could not parse

[~, a] = gracefoReading.readEventList('TN-01_SOE.txt');
fprintf('%d of %d line(s) unparsable\n', a.numUnparsable, a.numRows);
