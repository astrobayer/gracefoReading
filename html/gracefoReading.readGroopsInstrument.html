gracefoReading.readGroopsInstrument

Read a GROOPS ASCII instrument file.

Syntax

[time, data, info] = gracefoReading.readGroopsInstrument(fileName)

Description

Reads an ASCII instrument file in the convention written by gracefoReading.writeGroopsInstrument: a version line, a two-integer type and dimension header, a lone record count and one record per line starting with the decimal MJD. It is the counterpart of the writer and serves two purposes: roundtrip verification of the export, and reading GROOPS-produced series back into MATLAB for comparison with Level-1B data.

Input Arguments

NameTypeSizeDescriptionOptionsDefault
fileNamestring | char1x1Path to a GROOPS ASCII instrument file.
Validation: mustBeFile

Output Arguments

NameTypeSizeDescriptionOptionsDefault
timedouble[N x 2]Integer MJD and seconds of day recovered from the decimal-MJD column, matching the readL1b time layout.
datadouble[N x M]Data columns; M equals info.dataColumns.
infostruct1x1
  • version – double: version tag from the first line
  • typeCode – double: first integer of the header
  • dataColumns – double: declared number of data columns
  • numRecords – double: declared number of records

Accuracy and Limitations

  • The decimal-MJD time tag limits accuracy to about 1.3 microseconds around MJD 58849; a roundtrip through the writer reproduces epochs to that level, not to the nanosecond precision available from readL1b in "gpsns" format.
  • Only the ASCII instrument format is read; GROOPS binary files are not supported.
  • Declared record and column counts are enforced, which catches truncated files, but the type code is not interpreted: the function does not know what the columns mean. Consult the GROOPS documentation of the type code in info.
  • Header conventions have not been verified against a specific GROOPS installation (see writeGroopsInstrument limitations); files from a real installation may carry additional comment lines, which this reader does not expect.

Errors

Error identifierCondition
gracefoReading:readGroopsInstrument:badFormatfirst line or header lines not in the expected convention
gracefoReading:readGroopsInstrument:countMismatchdeclared record or column count does not match the data

Examples

roundtrip check of the exporter

gracefoReading.writeGroopsInstrument('acc.txt', t, acc);
[t2, acc2, info] = gracefoReading.readGroopsInstrument('acc.txt');
fprintf('max |dt| = %.3g s\n', ...
   max(abs((t2(:,1)-t(:,1))*86400 + t2(:,2)-t(:,2))));

compare a GROOPS-processed series with Level-1B data

[tg, dg] = gracefoReading.readGroopsInstrument('fromGroops.txt');
[tl, obs] = gracefoReading.readL1b('ACT1B_2020-01-01_C_04.txt');
