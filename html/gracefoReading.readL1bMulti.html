gracefoReading.readL1bMulti

Read and concatenate several GRACE-FO L1B ASCII files.

Syntax

[time, obs, aux] = gracefoReading.readL1bMulti(fileNames)
[time, obs, aux] = gracefoReading.readL1bMulti(fileNames, Name, Value)

Description

Calls gracefoReading.readL1b on each file (e.g. consecutive daily ACT1B files) and concatenates the results into one continuous record. All files must expose the same observation columns (aux.obsNames); a mismatch raises an error rather than silently joining incompatible data. Per-file provenance is preserved in aux, and the concatenated time series is checked for strict monotonicity, which catches wrong file order and duplicate days. All name-value options are forwarded unchanged to readL1b.

Accuracy and Limitations

  • Accuracy is that of readL1b; concatenation itself is exact.
  • Records are joined in the order given, not sorted. Overlapping or out-of-order files trigger the timeNotMonotonic warning but are still returned, so the caller can decide how to resolve the overlap.
  • Duplicate epochs are not removed automatically.
  • If 'TimeRange' or a quality option removes every record of every file, the result is empty rather than an error: time and obs are the same clean empties readL1b returns for one file, aux still carries fileNames, products, recordsPerFile (all zero) and the per-file record counts, and the outcome is reported by the noRecordsInRange warning. The monotonicity check is skipped, an empty series being trivially monotonic. Callers that require data should test isempty(time) or promote the warning with warning('error', 'gracefoReading:readL1bMulti:noRecordsInRange').
  • Memory grows linearly with the number of files; a full year of 1 Hz ACT1B is roughly 3e7 records. For long series, read in blocks or use 'CacheDir' with per-day processing.

Examples

five consecutive days

files = compose("ACT1B_2020-01-%02d_C_04.txt", 1:5);
[t, acc, aux] = gracefoReading.readL1bMulti(files);
disp(aux.recordsPerFile');

a month located by findL1bFiles, cached and flag-filtered

files = gracefoReading.findL1bFiles(archive, "ACT1B", ...
   'DateRange', [datetime(2020,1,1) datetime(2020,1,31)], ...
   'Satellite', "C");
[t, acc] = gracefoReading.readL1bMulti(files, ...
   'ApplyQualityFlags', true, 'CacheDir', 'l1bcache');

a range the files do not cover: empty, not an error

tr = [datetime(2019,12,31,0,0,0), datetime(2019,12,31,1,0,0)];
[t, acc, aux] = gracefoReading.readL1bMulti(files, 'TimeRange', tr);
if isempty(t)
   fprintf('%d file(s) read, no record in range\n', numel(aux.fileNames));
end
