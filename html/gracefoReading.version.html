gracefoReading.version

Version and release metadata of the gracefoReading toolbox.

Syntax

v = gracefoReading.version()
[v, info] = gracefoReading.version()

Description

Returns the toolbox version as a semantic version string, allowing downstream scripts and processing chains to assert a minimum version programmatically instead of trusting folder names. The second output adds release metadata. The version string is also part of the cache key used by readL1b, so caches written by an older toolbox are never reused after an upgrade.

Input Arguments

This function takes no input arguments.

Output Arguments

NameTypeSizeDescriptionOptionsDefault
versionStringchar[1 x C]Semantic version, e.g. '1.1.0'.
infostruct1x1
  • version – char: same as versionString
  • date – char: release date 'yyyy-MM-dd'
  • developedWith – char: authorship and model note
  • license – char: 'MIT'

Accuracy and Limitations

  • The version is a literal maintained in this file and mirrored in Contents.m and docsrc/functionSpecs.json; the consistency test testDocConsistency enforces that the three agree. Tests must never pin a version literal themselves, since that breaks on the next bump.
  • String comparison of semantic versions is lexicographic and only reliable while all components stay single-digit; for robust checks compare the numeric parts, e.g. sscanf(gracefoReading.version(), '%d.%d.%d').

Examples

simple assertion in a processing script

assert(string(gracefoReading.version()) >= "1.0.0")

numeric comparison, robust beyond version 9

% (this example asserted v >= 2.3 until 2026-09-08; the renumbering
%  from 2.3.0 to 1.0.0 left it impossible to satisfy, which is what
%  a runnable EXAMPLE section exists to expose)
v = sscanf(gracefoReading.version(), '%d.%d.%d')';
assert(v(1) > 1 || (v(1) == 1 && v(2) >= 0))
