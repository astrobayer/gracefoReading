Getting Started with gracefoReading

Installation, first read, and the batch workflow.

1. Installation

Unpack the toolbox anywhere and add it to the MATLAB path. Nothing is copied elsewhere, so deleting the folder removes the toolbox.

cd <toolboxRoot>
setupGraceFOReading            % path + doc registration, this session
% permanent: add the addpath call to your startup.m

Requires MATLAB R2020b or later or later (arguments blocks). Verify with:

addpath('ci'); results = runCI();   % all suites, reports in artifacts/
disp(table(results));

2. Read one product file

[t, obs, aux] = gracefoReading.readL1b('ACT1B_2020-01-01_C_04.txt');
disp(aux.obsNames');                       % what the columns mean
plot(t(:,2)/3600, obs(:, strcmp(aux.obsNames, 'lin_accl_x')));
xlabel('hours of day'); ylabel('m/s^2');

The reader takes column names, units and flag meanings from the file's own header, so the same call works for every Level-1B product.

3. Quality flags and gaps

[bits, report] = gracefoReading.decodeQualFlags(aux);   % meanings from the header
disp(report);
[t, obs, aux] = gracefoReading.readL1b(f, 'QualityBitMask', [6 7]);
[gaps, stats] = gracefoReading.findGaps(t);             % contiguous segments

4. Batch processing

files = gracefoReading.findL1bFiles(archive, "ACT1B", ...
    'DateRange', [datetime(2020,1,1) datetime(2020,1,31)], 'Satellite', "C");
[t, acc, aux] = gracefoReading.readL1bMulti(files, 'CacheDir', 'l1bcache');

With 'CacheDir' the second pass over the same files loads parsed results instead of re-parsing them; the cache key is a SHA-256 digest of file content and toolbox version, so it invalidates itself.

5. Export to GROOPS

gracefoReading.writeGroopsInstrument('acc.txt', t, acc(:,1:3));
[t2, d2, info] = gracefoReading.readGroopsInstrument('acc.txt');   % verify
