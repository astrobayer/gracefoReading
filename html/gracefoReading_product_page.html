gracefoReading Toolbox v1.3.2

GRACE-FO Level-1B ASCII data reading toolbox

Reads any GRACE-FO Level-1B RL04 ASCII product (ACT1B/ACC1B, SCA1B, KBR1B, LRI1B, GNV1B, THR1B, MAS1B, ...) into a common time/obs/aux layout, driven entirely by each file's own YAML header. Supports split microsecond time tags, bit-string quality flags, prod_flag-controlled variable-length records, gzip input, and strict row-integrity checking. Validated against real PO.DAAC RL04 files of 2020-01-01. Includes batch tools (file discovery, gap analysis, content-hashed parse caching), exact int64 GPS-nanosecond time output, selective quality-bit filtering, GROOPS instrument export/import, and experimental classic GRACE (2002-2017) support.

Getting Started

See the getting started page for installation, a first read and the batch workflow, and the PDF guide doc/gracefoReading_Guide.pdf for the complete manual.

setupGraceFOReading              % add toolbox to the path
[t, obs, aux] = gracefoReading.readL1b('ACT1B_2020-01-01_C_04.txt');
addpath('ci'); results = runCI();        % verify the installation
